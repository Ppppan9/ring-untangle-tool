# 解环 · After Effects 工程导出说明

## 使用步骤
1. 网页工具面板「导出 AE 工程」点「● 开始记录」，然后自动通关或手动游玩；点「■ 停止并导出」得到 `ring-untangle-tool_ae_export_*.zip`。开启「录制视频时同步记录」时，停止视频录制会自动导出。
2. 解压（保持 `build_ae_project.jsx`、`timeline.json`、`assets/`、`audio/` 在同一目录）。
3. After Effects（CC 2018+）→ 文件 → 脚本 → 运行脚本文件… 选 `build_ae_project.jsx`。脚本新建工程、导入素材、建立「主合成_解环」，弹出统计并询问另存 .aep。

> 提示没有写文件权限：编辑 > 首选项 > 脚本和表达式 勾选「允许脚本写入文件和访问网络」。

## 图层（从下到上）
- `背景` / `标题条`
- `环_<序号>_<颜色>`：每个环一个图层（3D 渲染的 PNG 精灵，自带它身上的扣子与投影），位置/旋转/缩放/不透明度关键帧 = 拖动旋转、飞出淡出、卡住抖动
- `手指`：位置/缩放（按压）关键帧
- `结束页`（如开启）
- `混合音轨` + 预合成 `音效_逐事件`；主合成每个音效一个标记
